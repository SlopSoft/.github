## What is SlopSoft?

SlopSoft is a collection of self-hosted software written
in Rust and unapologetically vibe-coded with AI.

We turn prompts into software you can run on your own
infrastructure. No mandatory cloud. No unnecessary
middlemen. Just you, your server, and a suspicious
amount of Rust.
